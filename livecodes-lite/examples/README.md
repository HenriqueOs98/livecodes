# LiveCodes Lite Examples

This directory contains examples demonstrating how to use LiveCodes Lite in different contexts.

## React Demo

A simple React application showing how to integrate LiveCodes Lite into a React project.

### Features

- Language selector (JavaScript, TypeScript, JSX, TSX, HTML, CSS)
- Theme toggling (light/dark)
- Code editing with syntax highlighting
- Demo code samples for each language

### Running the Example

```bash
# First, build the LiveCodes Lite library
cd ../
npm install
npm run build

# Then run the React demo
cd examples/react-demo
npm install
npm start
```

This will start a development server, and you can access the demo application at http://localhost:3000.
